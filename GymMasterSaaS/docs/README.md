## Project Overview

GymMasterSaaS is a multi-tenant gym management SaaS platform built with:
- **.NET 8** backend (Clean Architecture)
- **Next.js 14** frontend (planned)
- **SQL Server** database
- **Multi-tenant** architecture with Demo/Trial/Paid tiers
